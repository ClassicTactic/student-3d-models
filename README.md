# Student 3D Models

A shared library of 3D models for students to use in their projects (Blender, Unreal Engine, Roblox and more).

## How to download a model

1. Open the folder for the kind of model you need (see below).
2. Click the model's file name.
3. Click the **Download raw file** button (the down-arrow icon on the right).

To download everything at once, click the green **Code** button at the top of this page, then **Download ZIP**.

You don't need a GitHub account to download.

## Folders

| Folder | What's in it |
|---|---|
| `characters/` | People, creatures, robots |
| `props/` | Small objects: furniture, tools, weapons, food, items |
| `environments/` | Buildings, terrain pieces, rooms, modular level kits |
| `vehicles/` | Cars, ships, spacecraft, aircraft |
| `nature/` | Trees, rocks, plants |
| `textures/` | Image textures and materials shared by several models |

Each model gets its own subfolder, for example `props/wooden-crate/`, holding the model file(s), its textures, and a preview image.

## File formats

- **.fbx** – best for Unreal Engine and Roblox
- **.glb / .gltf** – one-file models with textures included; good for web and many engines
- **.obj** – simple, works almost everywhere
- **.blend** – the original Blender file, if you want to edit the model

## Using these models

Each model folder notes where the model came from and its license. Only use models in your projects the way their license allows, and credit the creator when the license asks for it.
